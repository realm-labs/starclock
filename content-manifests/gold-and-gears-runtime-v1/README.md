# Gold and Gears Runtime V1 Manifests

This root owns Goal 14 runtime assignment manifests. It does not replace or
modify the immutable Goal 08 source manifest.

`runtime-dispositions.json` and `rule-partitions.json` are generated by:

```text
node tools/goal14/generate-dispositions.mjs
node tools/goal14/generate-dispositions.mjs --check
```

The generator consumes the frozen Goal 08 content manifest, mechanic rules and
semantic fixtures under the hashes in
`policy/goal14-runtime-dispositions.json`. Do not hand-edit the generated
files. Change the policy or generator and regenerate the complete targets.

The disposition manifest assigns each of 7,913 source obligations, 1,224
mechanic rules and 18 semantic fixture families exactly once. `Pending` is an
execution state, not a disposition: the target disposition and owning batch
are frozen here, while later batch receipts must prove terminal implementation.

The partition manifest fixes the stable rule IDs owned by `G14-P5-M01` through
`G14-P5-M09`. A later batch may not move, omit or duplicate an assigned rule to
make coverage pass.
