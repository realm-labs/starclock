# Core combat content manifests

These manifests describe the current core-combat content set. They bind the
prepared Version 4.4 content-reference pack, cover all 88 released combat forms
and 165 released Light Cones, select the representative public Standard subset,
and assign deterministic authoring partitions.

The prepared JSON remains gameplay reference material and deterministic
bootstrap input only; it is not a runtime catalog or a historical status
ledger.
