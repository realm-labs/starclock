# Swarm Disaster V1 Manifests

This directory owns the frozen Version 4.4 source, denominator, ownership and
coverage manifests for Goal 09. It is isolated from Standard Universe, Gold
and Gears and other mode manifests.

`source-inventory.json` is generated by:

```text
node tools/swarm-disaster-reference/inventory.mjs
node tools/swarm-disaster-reference/inventory.mjs --check
```

The inventory hashes raw Git blob bytes at the two pinned revisions, avoiding
checkout-specific newline drift. Its file families are research inputs, not
content-row ownership or reachability decisions. Those exact row-level
decisions are frozen separately by `G09-P0-B3`.

The inventory treats `RogueDLC*` as a shared framework. It distinguishes the
109 non-`MapRepo160` topology files used as Swarm candidates from 115
`MapRepo160` Gold and Gears exclusion files, and retains all 32 `RogueDLC`
tables for row-level `ChessRogue` review. A prefix, display name or adjacent ID
never grants membership.

The local ignored source cache may be reproduced through
`tools/content-reference/fetch-sources.ps1`. A worktree may also point its
ignored cache paths at an existing detached, clean checkout of the exact
pinned revisions.
