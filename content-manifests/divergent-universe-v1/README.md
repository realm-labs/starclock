# Divergent Universe V1 Manifests

This directory owns the frozen Version 4.4 source, denominator, ownership and
coverage manifests for Goal 11. It is isolated from Standard Universe, Gold
and Gears, Swarm Disaster, Unknowable Domain and other-mode manifests.

`source-inventory.json` is generated by:

```text
node tools/divergent-universe-reference/inventory.mjs \
  --source-cache <cache-root>
node tools/divergent-universe-reference/inventory.mjs --check \
  --source-cache <cache-root>
node tools/divergent-universe-reference/verify-inventory.mjs \
  --source-cache <cache-root>
```

The inventory hashes raw Git blob bytes at the two pinned revisions, avoiding
checkout-specific newline drift. It inherits every Goal 03 source file, adds
the focused Divergent Universe configuration, StageConfig and TextMap entries,
and retains nine bilingual public indexes for identity cross-checking.

File families are research inputs, not content-row ownership or reachability
decisions. `G11-P0-B3` freezes those exact row-level decisions. A
`RogueTourn` prefix, module number, ID range, adjacent record or matching
localized name never grants membership; shared records require an explicit
selector, transitive reference or inherited stable-ID closure.

The ignored source cache is reproduced through
`tools/divergent-universe-reference/fetch-sources.sh`. Both repositories must
be clean, detached and at the exact revisions frozen in `foundation.json`.
