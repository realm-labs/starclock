# Unknowable Domain V1 Manifests

This directory owns the frozen Version 4.4 source, denominator, ownership and
coverage manifests for Goal 10. It is isolated from Standard Universe, Gold
and Gears, Swarm Disaster and other-mode manifests.

`source-inventory.json` is generated by:

```text
node tools/unknowable-domain-reference/inventory.mjs
node tools/unknowable-domain-reference/inventory.mjs --check
node tools/unknowable-domain-reference/verify-inventory.mjs
```

The inventory hashes raw Git blob bytes at the two pinned revisions, avoiding
checkout-specific newline drift. It inherits every Goal 03 source file, adds
the focused Unknowable Domain configuration, StageConfig and TextMap entries,
and retains nine bilingual public indexes for identity cross-checking.

File families are research inputs, not content-row ownership or reachability
decisions. `G10-P0-B3` freezes those exact row-level decisions. A `RogueMagic`
prefix, ID range, adjacent record or matching localized name never grants
membership; shared records require an explicit selector, transitive reference
or inherited stable-ID closure.

The ignored source cache is reproduced through
`tools/unknowable-domain-reference/fetch-sources.sh`. Both repositories must be
clean, detached and at the exact revisions frozen in `foundation.json`.
