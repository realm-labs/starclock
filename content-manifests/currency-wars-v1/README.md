# Currency Wars V1 Manifests

This directory owns the frozen Version 4.4 source, denominator, ownership and
coverage manifests for Goal 12. It is isolated from Standard Universe, Gold
and Gears, Swarm Disaster, Unknowable Domain, Divergent Universe and every
other mode.

`source-inventory.json` is generated by:

```text
node tools/currency-wars-reference/inventory.mjs \
  --source-cache <cache-root>
node tools/currency-wars-reference/inventory.mjs --check \
  --source-cache <cache-root>
node tools/currency-wars-reference/verify-inventory.mjs \
  --source-cache <cache-root>
```

The inventory hashes raw Git blob bytes at the two pinned revisions, avoiding
checkout-specific newline drift. It inherits every Goal 03 source file, adds
the focused Currency Wars S3 configuration, all 22 shared Tourn Maze graphs,
three Tourn service graphs, the Tourn1 modifier as explicit module-boundary
evidence, StageConfig and TextMap entries, and nine bilingual public indexes.

All 11 `RoguePersona` and all 64 `RogueTourn` source tables are included. The
generated audit records each table's top-level row count and conservative
indexes for rows containing an explicit `Tourn3`, MainTourn 3 or Activity
Module 6002201 selector. This audit prevents a selected row from disappearing,
but it is not the final ownership or reachability classifier.

File families and the row audit are research inputs, not content denominators.
`G12-P0-B3` freezes exact row obligations and ownership. A Persona/Tourn
prefix, `_S3` suffix, module number, ID range, adjacent record or matching
localized name never grants membership; shared records require an explicit
enabled selector, transitive reference or inherited stable-ID closure.

The ignored source cache is reproduced through
`tools/currency-wars-reference/fetch-sources.sh`. Both repositories must be
clean, detached and at the exact revisions frozen in `foundation.json`.
