# Fate/Star Rail Night Reference V1

This directory contains the normalized, reference-only Goal 19 pack. The
machine contract is generated by `tools/fate-star-rail-night-reference/contracts.mjs`
and binds the 1,904-obligation manifest, canonical encoding, evidence and
reconciliation fields, semantic fixture language and four-workbook partition.

The pack is Candidate authoring evidence only. Runtime code must not load its
JSON files or treat its Sora review bundle as released configuration.
