## Current authored boundary

`RewardOccurrences` in the production decision workbook selects one executable,
free reward occurrence for the reviewed level-one Reward preset `1010`.
`authored_reward_occurrence_room_compiler` requires its typed project key and
the exact reviewed card/preset/level. Missing selections, other card kinds,
unadmitted presets and changed levels reject before producing a fragment.

This is `VersionedProjectPolicySingleExplicitRewardOnlySubstituteNoPoolSampling`,
not original event-pool parity. The selected A Dash of Color program is a
reward-only substitute; neither its existence nor its public description proves
membership in the current Reward-type pool. Its already authored choices grant
200 Fragments, two Curios or two Blessings through the shared reward/acquisition
engine and its separately declared candidate policy. No new event selector RNG,
second event state machine, implicit entry payout or marker reward is introduced.

The returned `CompiledOccurrenceRoom` carries the typed selection key in its
configuration digest. Explicit caller placement of the same event does not
alias this authored admission. Whole-profile identity and binding use
`position_room_identity_with_occurrences` and
`bind_position_rooms_with_occurrences`. See the existing
[position occurrence contract](divergent-universe-position-occurrences.md).

## Execution and verification

Data validation requires a unique reviewed Reward preset, level one, an
executable nonempty free occurrence, nonempty reward outcomes, policy metadata
and provenance. Tests load the real production Sora bundle and reject malformed,
paid, empty, duplicate and unadmitted bindings.

Ordinary and Cyclical position fixtures prefer Reward only among the actually
sampled cards. All three reward choices execute, with inventory/credit changes
before `RoomFinished`, and `RoomFinished` before opening the exit. Acquisition
draws are included in Curio accounting. Reward selection stays at the same
physical node; Leave is a separate Route command. Later logical rooms reset the
completion flags and dispatch through the shared baseline controller. Raw,
stale, repeated and overflow-failing choices preserve authoritative bytes/RNG;
overflow is retryable. Fresh factories reconstruct the same transactions,
accepted steps and canonical states through three real nested Boss proxy battles.

Deck hints and Boss selection remain fixture policies. Other room payloads are
probes. Original Reward event pools, higher-level programs, NPC graphs, default
full topology and encoded source-position profile replay remain pending.
No terminal source/mechanic, Reward-family or complete-run coverage is credited
by this partial implementation.
