# Goal 07 Release Contract

Goal 07 releases complete Version 4.4 Standard Universe mechanics on the
Goal 06 dynamic per-battle assembly boundary. The immutable release identity
is `standard-universe-mechanics-complete-v1`.

## Released boundary

The release binds all 2,201 content records, 786 mechanic rules, 78 semantic
fixtures, 86 enemy variants and 173 encounter members to exact-once terminal
dispositions and production execution evidence. The 104 generated content
partitions and 17 fixed batches form the frozen 121-batch ledger.

Combat and noncombat behavior enters the runtime through shared Rule IR,
Activity transactions and the Goal 06 assembly boundary. No content-specific
native handler was admitted. All 73 numeric candidates have terminal
dispositions: 24 use exact public values and 49 use named, replaceable,
evidenced approximations; mechanic approximations remain prohibited.

## Frozen evidence

The release binds:

- all 104 ordered partition receipts and exact-once coverage denominators;
- production Excel/Sora regeneration, bilingual and licensed provenance
  audits;
- targeted mechanic, lifecycle, dynamic inventory and interface parity
  scenarios;
- 33 constructible World/difficulty runs containing 154 production battles,
  1,048 accepted battle command/state pairs and 1,903 replay actions;
- rollback, concurrency, RNG isolation and long-run resource/charge probes;
- stable-runner performance and allocation budgets over complete content;
- native execution contracts for Windows x64, Linux x64 and macOS ARM64,
  with three alternate targets explicitly compile-only.

The machine-readable release evidence is generated and verified by:

```text
node tools/goal07/verify-release-contract.mjs . --release
```

The final completion tree is registered separately in
`policy/release-snapshots.json`. Later work may evolve current source and CI
inventories, but it may not rewrite the Goal 07 completion tree.

## Evidence boundary

The release claims mechanism-correct Standard Universe behavior for the
frozen Version 4.4 scope. It does not claim runtime support for expansion
profiles whose rows remain explicitly `ProfileExcluded`, nor does it promote
compile-only targets to native execution evidence.
