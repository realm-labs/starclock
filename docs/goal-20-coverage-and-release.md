## Policy, performance and CI

All 31 Goal 09 policy boundaries close as versioned executable policy,
metadata, stronger evidence or an explicit terminal blocker. None remains
inherited or pending at release. Project policies and synthetic battle values
remain visibly distinct from observed numeric parity.

Seven stable workloads cover catalog lowering, all matrix entries, full-run
replay, trigger-heavy dice/topology work, warm battle assembly identity,
concurrent shared catalogs and invalid-command/replay corruption. Structural
budgets forbid per-run catalog clones, repeated composition, replay-prefix
reconstruction and allocation in 10,000 warm cache reads.

Windows x64, Linux x64 and macOS ARM64 must execute the same Swarm goldens.
Windows ARM64, Linux ARM64 and macOS x64 remain compile-only and never count as
runtime evidence.

## Release boundary

The release scaffold requires all 51 batches, 6,963/23/23 exact-once terminal
coverage, all 31 terminal policies, fresh matrix verification, interface
parity, hardening, performance, source-cache and clean-checkout audits. P8-B4
creates the completion evidence; snapshot registration occurs separately only
after hosted native evidence binds that exact commit.
