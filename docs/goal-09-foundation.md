`G09-P0-B1` starts `swarm-disaster-reference-v1` from the registered Goal 03
completion tree. Goal 09 produces a Candidate-quality Swarm Disaster reference
bundle. It does not lower that bundle into the runtime or change shared runtime
operations, schemas or generated readers.

`457d05f0e3a7b6fe3abb7e8f142f96fa271f5ecd` with tree

are evidence for Goal 09.

## Scope boundary

Goal 09 includes released-source inventory, mechanically relevant Swarm
systems, pool ownership and reachability, encounter identities, semantic
review fixtures, isolated Sora tables/readers and isolated Excel workbooks.
Story presentation, dialogue prose and account/collection rewards are excluded
except where a mechanical unlock locator is required.

The goal ends at a Candidate reference bundle. Runtime lowering, integration,
controller/API exposure and seeded complete runs belong to a later goal.
Standard Universe, Gold and Gears, Unknowable Domain, Divergent Universe and
other-mode rows fail closed unless a Swarm Disaster reachability edge is
proven.

## Parallel artifact isolation

Goal 09 runs on a `codex/goal09-*` branch and owns only its named artifact
roots:

- `content-manifests/swarm-disaster-v1/`
- `content-reference/swarm-disaster-v1/`
- `config/swarm-disaster/`
- `config/swarm-disaster-generated/`
- `tools/swarm-disaster-reference/`
- `evidence/swarm-disaster-reference-v1/`

It must not mutate Standard reference manifests/workbooks, production
`config/generated/`, Standard staging `config/universe-generated/`, Gold and
Gears artifacts, Unknowable Domain artifacts, completed Goal 03 evidence or
Goal 07 tooling and partitions.

At the startup audit, Goal 08 ran on
`codex/goal08-gold-gears-reference`, Goal 09 ran on
`codex/goal09-swarm-disaster-reference`, and the newly prepared Goal 10 ran on
`codex/goal10-unknowable-domain-reference`; Git reported three distinct
worktrees. The path contract remains valid even after any one of those
worktrees is retired.

## Execution shape

The plan contains 29 atomic batches across five phases. Phase 0 freezes source,
denominator and authoring contracts before broad import. Every later content
batch owns its normalized rows, bilingual mechanical summary, evidence,
coverage and semantic fixtures. Excel is authoritative, Sora 0.3.0 owns schema
export, and JSON remains staging/debug data only.
