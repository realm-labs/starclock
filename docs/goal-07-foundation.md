# Goal 07 Foundation

`G07-P0-B1` starts `standard-universe-mechanics-complete-v1` from the
registered Goal 06 completion tree. Goal 07 extends content and shared
mechanic capability; it does not recreate combat identity, replay v3 or
current-Activity per-battle assembly.

## Frozen prerequisite

The direct prerequisite is Goal 06 completion commit
`c84c1a4572024355a1e30d41755133c486b1f4c7` with tree
`e37fbe11473541dbc41e54fcfb969d1428549dbe`. The snapshot is registered in
`policy/release-snapshots.json` and its release contract assigns the remaining
Standard Universe content work to Goal 07.

## Execution shape

The plan contains 17 fixed batches and 15 content milestones across eight
phases. `G07-P0-B3` expands the content milestones into bounded, ordered
`Snn` batches and freezes the final commit denominator before broad content
implementation begins.

Every content batch owns its Excel edits, Sora export, runtime lowering,
production-state fixture, provenance and coverage update. JSON remains a
staging/debug representation and cannot become a second authoring surface.
