# Goal 07 Retained-Mechanic Audit

`G07-P0-B2` converts the Goal 05 integration disposition into a deterministic
Goal 07 closure audit. The committed manifest assigns all 2,201 content
records, 786 mechanic rules and 78 semantic fixtures to a mechanism family,
shared primitive, evidence gap and intended terminal runtime/accuracy
disposition.

The audit additionally covers the 86 referenced enemy variants and 173
encounter members. The 73 current enemy proxies target mechanism-correct
definitions and AI while permitting only named numeric approximation.

## Native-handler candidates

Goal 04 used `StaticNativeHandler` for 427 mechanic rules as a typed planning
disposition. Goal 07 does not treat that label as an admission. The mirrored
record/rule audit entries target
`ExecutableRuleIr` by default and carry an explicit native-review candidate
flag. `G07-P1-B6` may admit a static mode-owned handler only after proving the
shared IR cannot reasonably express the mechanic.

## Evidence interpretation

- typed evaluator output is not production execution;
- Goal 05 `Integrated` rows still need an exact Goal 07 terminal disposition;
- metadata has no runtime body but must remain referenced exactly once;
- selection policies need deterministic candidate/weight proof;
- `ProjectPolicy` occurrence behavior must be replaced by public mechanics or
  justified as an explicit external decision;
- every semantic fixture must execute against production definitions.
