# Goal 20 Release Contract

Goal 20 releases the Version 4.4 Simulated Universe: Swarm Disaster Activity
profile over the immutable Goal 09 Candidate bundle and the released generic
Activity/Battle boundaries. Its immutable identity is
`swarm-disaster-runtime-v1`.

## Released boundary

The release binds all 6,963 source obligations, 23 mechanic rules, 23 semantic
fixture families and 31 inherited policy boundaries to exact-once terminal
runtime dispositions. The private 65-table, 33,380-row Sora bundle lowers into
immutable catalogs; production runtime paths read no normalized JSON or
workbooks and admit no native content handler.

The runtime executes the bounded three-plane graph, Countdown and Planar
Disarray, eight Audience Dice and 42 faces, Communing Device and Trail
progression, Pathstrider objectives, Paths/Resonance/Interplays, released
content and services, encounter selection and real nested battles. Explicit
project policies and synthetic fallback values do not claim unpublished engine
or balance parity.

## Frozen evidence

The release binds:

- 16 valid seeded complete runs covering five difficulties, eight Path/Die
  pairs, every reachable face, Countdown/Disarray boundaries and 31 policies;
- 404 real nested-battle executions across primary and fresh verification;
- component-addressed replay plus baseline, CLI, agent and MCP offered-command
  parity over one immutable runtime factory;
- separate Activity-command, Battle-command, event/state, replay and
  eight-domain RNG goldens plus bounded malformed-input corpora;
- seven stable performance workloads, including 10,000 allocation-free warm
  assembly-identity reads and 16 concurrent shared-catalog sessions; and
- dependency/license, architecture, native-handler, provenance, generated
  drift, source-cache, prior-release and fresh clean-checkout audits.

The machine-readable release is generated and checked with:

```text
node tools/goal20/verify-release-contract.mjs . --release
```

## Native and snapshot boundary

Windows x64, Linux x64 and macOS ARM64 execute the same Goal 20 hardening
goldens in hosted CI. Successful artifacts must bind the exact P8-B4
completion commit. Windows ARM64, Linux ARM64 and macOS x64 remain compile-only
and make no runtime claim.

The P8-B4 completion commit is registered separately in
`policy/release-snapshots.json` only after those hosted jobs succeed. Their
receipts belong in
`evidence/swarm-disaster-runtime-v1/release/hosted-native-ci.json`. Later work
may evolve current source but may not rewrite the frozen completion tree.

## Accuracy boundary

The release claims deterministic execution of frozen released facts and
explicit versioned policies. The synthetic balance-independent roster,
reviewed enemy behavior donors, minimum-stat fallbacks and unpublished joins
remain documented limitations, not observed parity. Story presentation,
account rewards, achievements and assets remain outside the runtime boundary.
