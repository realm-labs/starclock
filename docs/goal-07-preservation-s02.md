# Goal 07 Preservation Partition S02

`G07-P2-M02-S02` completes 16 records, 16 rule records and eleven
native-handler reviews. The partition covers the two released levels of
Solid Solution, Safe Load, Sanctuary, Quadrangular Pyramid, Hypoeutectoid and
the first level plus definition of Assemble. No native handler is admitted.

## Authoritative authoring boundary

The formal authoring source remains:

- `Universe.xlsx`: Blessing definitions, levels and exact parameters;
- `UniverseBindings.xlsx`: definition and level mechanic-rule bindings;
- `UniverseEvidence.xlsx`: retained audit and provenance records.

`tools/goal07/author-path-partition.py` reads the workbooks through
`openpyxl`, rejects formula or spreadsheet-error cells, verifies exact
assignment and provenance, and compares every assigned value with Sora 0.3.0
debug output. Runtime code consumes the validated `.sora` bundle rather than
the workbook or staging JSON.

## Exact mechanics

All ratios below use six-decimal fixed point. `Shield` is the owner's current
effective shield, `BaseATK` is the immutable authored base Attack, and
`MaxHP`/`DEF` are current derived stats unless explicitly named otherwise.

### Interstellar Construct: Solid Solution (`612042`)

The level values complete the formula introduced by S01:

```text
DEF contribution(L1) = 0.80 * DEF
DEF contribution(L2) = 1.20 * DEF
Quake = (Quake base + DEF contribution) * (1 + Quake boost)
```

This remains a shared formula primitive composed into the originating Quake;
it is not a shield-strength modifier.

### Construct: Safe Load (`612043`)

The owner gains a dynamic flat Attack bonus while shielded:

```text
bonus ATK(L1) = min(0.40 * Shield, 1.20 * BaseATK)
bonus ATK(L2) = min(0.60 * Shield, 1.60 * BaseATK)
```

The value is recomputed from current shield at the stat-query boundary.
`BaseATK` bypasses derived-stat recursion, so another Attack modifier cannot
raise this cap.

### Construct: Sanctuary (`612044`)

At the end of each owner turn:

```text
L1: 80% fixed chance, shield = 0.12 * MaxHP
L2: guaranteed,       shield = 0.15 * MaxHP
duration = 1 owner turn
```

The previous source-scoped Sanctuary shield and effect are removed before a
new application. A failed L1 chance therefore does not retain the previous
shield.

### Construct: Quadrangular Pyramid (`612045`)

The two levels intentionally affect different sides of shield creation:

```text
L1: shield generated by the owner +30%
L2: shield received by the owner  +35%
```

Formula-subject metadata distinguishes source-side generation from
target-side reception. A self-shield is modified once, not once by each side.

### Construct: Hypoeutectoid (`612046`)

When the owner grants a positive shield amount to another ally:

```text
provider shield(L1) = 0.24 * shield actually granted
provider shield(L2) = 0.36 * shield actually granted
duration = 2 owner turns
```

The rule reads the completed shield-change fact, requires event target and
rule owner to differ, and triggers once per action. Reapplication replaces
the source-scoped provider shield and refreshes its two-turn counter.

### Construct: Assemble (`612050`)

The S02 level is:

```text
DEF bonus(L1) = 0.06 * min(owned Preservation Blessings, 6)
```

The contribution compiler counts the validated selected Blessings, including
Assemble itself, before battle materialization. The enhanced level is assigned
to S03.

## Generic core additions

The partition adds reusable concepts only:

- `QueryBaseStat`, separate from a derived-stat query;
- current shields visible to dynamic modifier expressions;
- `FormulaSubject::Source` and `FormulaSubject::Target` filters;
- global `FormulaPurpose::Stat` modifiers applying to contextual stat reads;
- executable modifier groups and definitions carried by lowered mode rules;
- rule-triggered operations attributing an absent event applier to the rule
  owner, required for battle-start effects;
- exact shield deltas and source-scoped shield replacement through existing
  Rule IR operations.

No Blessing ID or Standard Universe branch enters `starclock-combat`.

## Production verification

The production materialization tests prove:

- Safe Load L1/L2 cap a 100-ATK owner at 220/260 effective ATK, producing
  exact direct-damage facts of 110/130 in the fixture;
- Sanctuary plus Quadrangular Pyramid creates 15,600 and 20,250 shields for
  the L1/L2 combinations;
- Assemble's selected-Blessing count changes current DEF before Solid
  Solution is folded into Quake;
- granting an ally a 1,000 shield creates exact 240/360 provider shields and
  does not recurse;
- both Solid Solution levels, all five S02 definition families and every
  selected level flow through the production catalog and battle resolver.

Core tests independently cover dynamic shield/base-stat queries and
source/target formula filtering. The completion receipt is
`evidence/standard-universe-mechanics-complete-v1/partitions/G07-P2-M02-S02.json`.
