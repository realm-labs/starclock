# Divergent Universe Wealth chest pickups

## Executable contract

`coin_room` compiles an explicitly collected chest reward at current reviewed
`Card(Coin)` or `Fixed(Coin)` source contexts. The upstream kind `Coin` displays
as Wealth; it does not describe a complete domain containing only currency.
Amusement facilities remain unimplemented.

Production `DivergentUniverseDecisions.xlsx` contains three `CoinRewards` rows:

| Reviewed preset | Level | Policy base Fragments |
| --- | ---: | ---: |
| 1008 | 1 | 100 |
| 1024 | 2 | 200 |
| 9008 | 1 | 100 |

Preset/kind/level joins preserve the reviewed structured source records;
obfuscated field-role interpretation remains the existing layout/deck policy.
Amount, one aggregate
pickup per logical room and explicit collection timing are replaceable policy,
not recovered original chest selectors, quantities or observed parity.
Compilation joins only previously reviewed source cards/fixed positions;
unknown, fabricated, non-Wealth or unmatched contexts reject.

The shared Activity graph runs the existing Curio domain-entry prefix once,
then offers Collect and Leave. Neither compilation nor entry automatically
pays the chest. Collect credits the authored base through the existing full
active-Curio Fragment-gain pipeline, adds one independent Run receipt
(`0x2264_0001`), and exits. Leave grants no chest credit or receipt. Both choices
are authenticated and guarded; raw shared choices cannot bypass the capability.
The fragment has no reward draws or random offers. Its exit may enter another
domain's ordinary routing or random-offer work.

Credit, Curio modifiers, receipt, choice guard, scope changes and next-room
entry share one generated-choice transaction. Balance/receipt overflow or
downstream failure restores canonical state and RNG, retaining the same offer.
Successful pickup exits a one-visit menu; repeated or stale selections reject.
No extra mutation engine, RNG stream, formula or replay format is introduced.

The compiler digest binds exact current bundle inputs, selected reward/policy,
host slot, placement and scope addresses. The owning profile must bind all
remaining immutable inputs. Binding checks exact nodes, programs, Curio entry
prefix, declaration, edges, logical Run/Plane/Node paths and the absence of room
random policies. Extra exits, outside entries into the menu and starting the
graph at the menu reject. A bound capability authenticates the entire running
definition; matching claimed identities cannot authorize foreign tail programs,
participants or handler bindings. Fresh structurally identical definitions work.

`bind_position_coin_rooms` attaches these capabilities to an existing immutable
position battle profile. The Flow's `offered_coin_chest` and `choose_coin_chest`
and the baseline controller use this same authenticated boundary. Empty,
duplicate, repeated, foreign-context or changed-slot attachments reject.
No default CLI/Agent/MCP source-position topology or encoded profile reconstruction
is supplied by this attachment API.

## Verification and remaining scope

Data tests load the production Sora bundle and reject invalid identity,
preset/level joins, amount encodings/ranges, policy metadata and provenance.
Isolated source-context fixtures execute both choices for all three authored
presets, including the level-two card and fixed guide chest. They cover raw
choice rejection, program/scope/edge/random-offer tampering, menu-entry bypass,
same-identity foreign tail programs and late exit rollback.

Ordinary/Cyclical position fixtures select actual sampled Wealth and Shop cards,
collect policy Fragments and make actual production-stock purchases from zero
initial funds. Three real nested Boss proxy battles complete; fresh factories
reconstruct identical accepted steps and canonical states. Controller hints
prefer Wealth until the first pickup, then Shop, only among actually offered
cards. Active Curio 9055 changes a base-100 chest into 150; leaving still grants
nothing. Balance and receipt overflow, stale, hidden, foreign, unbound and
repeated selections preserve authoritative bytes.

Deck admission, hints and Boss selection are fixture policies; other payloads
remain probes. These tests are not encoded source-position replay or complete
released profile acceptance. Original amounts/counts/timing, facilities, NPC/
mask admission and default full topology remain pending. No terminal source,
mechanic, Wealth-family or full-run coverage is earned by this partial boundary.
