# Isolated Sora binding schema

The binding partition defines 12 primary tables in
`AnomalyArbitrationBindings.xlsx` for pool audits, traits, MazeBuff bindings,
battle events, encounters, waves, slots, enemies, skills, statuses, ability
bindings and mechanic contributions.

Stage-to-encounter, encounter-to-wave/slot and enemy-to-skill relationships
use typed Sora references. Upstream numeric IDs remain text locators. The
schema is generated by its dedicated repository tool, checked for drift and
validated with pinned Sora 0.3.0; it does not target production or another
mode's workbook.
