# Content-pool audits

The active Version 4.4 selector closure was evaluated independently for six
families: Blessings, Curios, Occurrences, gameplay services, gameplay
currencies and other random content pools. Each family has zero reachable
members and a distinct generated closure digest.

The closure begins at group 8, aliases 801–804, boss alias 804, the five
StageConfig rows, active targets, MazeBuffs, battle events and mechanical
constants. Membership requires an explicit selector, direct reference or
transitive stable-ID reference. Prefixes, adjacent IDs, shared-table presence,
matching names and account reward/shop locators do not grant membership.

Each zero proof can be replaced only when released active evidence names a
member. This audit does not claim that the upstream game contains no such
content globally; it proves only that the active Anomaly Arbitration profile
cannot reach it.
