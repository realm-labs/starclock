# Isolated Sora mechanics schema

The second schema partition adds nine primary tables in
`AnomalyArbitration.xlsx`: King states, protection, clocks, Quadrant options
and selections, targets, objectives, stage results and aggregations.

Every row retains stable identity, bilingual authoring text, evidence and
mechanism quality, manifest/source relationships, the complete canonical
payload and a non-runtime flag. Profile and stage relationships use typed Sora
references; upstream numeric target and Quadrant IDs remain text source
locators rather than workbook identity.
