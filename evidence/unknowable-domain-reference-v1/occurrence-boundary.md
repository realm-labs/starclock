# Unknowable Domain Version 4.4 Occurrence boundary

The explicit type `260` selector reaches 62 shared Occurrence handbook
identities. Each handbook supplies one distinct mode progress binding after
duplicate progress entries are collapsed, producing 62 exact handbook-to-graph
edges over 50 `RogueMagicNPC` graphs. Eight NPC graphs are shared by more than
one handbook; their complete handbook sets are retained, with the lowest stable
handbook ID used only as the canonical value required by the singular schema
field.

The 50 roots contain 68 ordered option nodes and 239 mechanical choices. Every
choice retains its option-list locator, bilingual label/result digests,
eligibility fields, option values and an independent ordered mechanical
summary. Three choices explicitly produce a Decision Component. Fifty-one
choices expose localized negative-operation cost boundaries.

Forty-six choices mention random or chance behavior without a published
percentage and therefore remain `Unspecified`. Hidden candidate sets, weights,
effect ordering beyond the released option result, and no-legal-choice
fallback are not invented.

Dialogue lines, story text, performance tasks, images and account rewards are
excluded. NPC and option configuration paths are evidence for graph topology;
the pack does not copy presentation prose and does not lower any choice into a
runtime handler.
