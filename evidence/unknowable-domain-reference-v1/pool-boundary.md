# Unknowable Domain Version 4.4 pool boundary

The fixed Version 4.4 snapshot proves **zero Blessings** for Unknowable Domain.
No released `RogueBuff` row carries a `MagicRogue` or mode-type `260` selector,
and no `RogueMagic` table references a shared Blessing. Components are a
separate mode-owned system and cannot be used to import a generic Blessing pool.

Shared Curios and Occurrences are reachable only through their explicit type `260`
handbook selectors. Their pool weights are not published. Components are
recorded in the mode-owned catalog with eligibility
`CatalogOwnedNotOfferProven`; the source publishes no Alignment-to-Component
selector, so the pack does not turn the catalog into an offered style pool.

The four Alignment records retain six explicit style-matched Scepters each.
Table prefixes, adjacent ID ranges, icon grouping, matching names and localized
effect prose do not create pool membership. Stronger released selectors or
reproducible observations must replace any unresolved pool or weight field.
