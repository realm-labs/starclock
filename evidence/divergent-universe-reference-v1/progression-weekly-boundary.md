# Permanent Progression and Weekly Boundary

This dossier freezes the `G11-P1-B9` boundary for the Inspiration Circuit,
unlock tokens, common constants, weekly candidates and room marks.

## Inspiration Circuit

All 38 permanent talents retain exact item `281018` costs, bilingual
mechanical descriptions, canonical parameters and one normalized battle or
activity contribution. The set contains 29 battle contributions and 9
activity contributions.

`NextTalentIDList` is demonstrably bidirectional: rows point both toward lower
and higher neighboring nodes. It is retained as adjacency and is not relabeled
as a directed prerequisite. `prerequisite_ids` remains empty until a released
directed progression source is available.

## Unlock tokens

All 97 tokens retain their exact finish-way locator. A stable join from
`UnlockFinishWay` to selected Tourn3 area rows proves eight tokens with 14
current area edges. Every other token remains consumer-empty; neither matching
numeric shape nor collection/reward use promotes it into simulation content.

## Common constants

All 34 constants retain canonical integer, string or array values. Eighteen
simulation-visible locators cover entry/mapping, Equation categories,
period/module selection, Titan/Boon configuration and Practice unlock.
Sixteen reward, account/archive, handbook-quest, share-code and God Mode/test
constants are retained as explicit exclusions.

## Weekly candidates

All 103 weekly rows resolve their content/detail displays and retain display
parameter locators plus enemy display-group references. The table exposes no
Tourn3 or activity-module selector. Consequently, every row remains an
`UnprovenCurrentWeeklyCandidate`; reward IDs are excluded and enemy identities
are deferred to `G11-P2-B5`.

## Room marks

Twenty-four rows define 12 room types and Base/Enhance/Double/Choice variants.
They publish display/icon identity but no trigger, probability, stacking,
choice or teardown program. Transition arrays therefore remain empty with
`PreserveCurrentMark` fallback.

Promotion requires an exact released consumer or transition program. No
source-table prefix, ID range, display name or adjacency is sufficient.
