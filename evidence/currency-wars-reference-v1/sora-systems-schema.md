# Currency Wars systems Sora schema

Batch `G12-P3-B2` extends the isolated project from 22 to 60 authoring tables.
The 38 added source-shaped tables cover:

- role mapping, positions, Character Empowerments and battle overrides;
- Bonds, levels and contributions;
- star states, combination and lifecycle;
- owned/trial build boundaries, off-field conversions and equipment; and
- Augment, Portal, Orb, Projection, Talent, enhancement and module-ban
  catalogs.

The same common bilingual/provenance envelope, private numeric workbook key,
unique stable-key index and canonical JSON boundary apply to every table. The
project still reads only `CurrencyWars.xlsx`; it neither imports the production
schema nor lowers any mechanic handler.

The owning generator reproduces both schema segments and the project file
byte-for-byte. The checksum-bound Sora 0.3.0 `check` command accepts all 60
tables and rejects duplicate table identities or invalid sheet names.
