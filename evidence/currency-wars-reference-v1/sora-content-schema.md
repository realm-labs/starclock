# Currency Wars content Sora schema

Batch `G12-P3-B3` extends the isolated project from 60 to 94 authoring tables.
The 34 added tables include:

- the proven empty Blessing/formula and Curio/Hex families plus seven exact
  non-Blessing enhancements;
- event, variant and choice graphs;
- currencies, shops, service offers and canonical empty Adventure families;
- encounter source obligations, Camps, waves, enemy slots and boss
  boundaries; and
- exact mechanic-source dossiers and reference-only mechanic rules.

The first 32 tables source `CurrencyWarsBindings.xlsx`; the two mechanic tables
source `CurrencyWarsReview.xlsx`. Every schema row retains the common
bilingual/evidence envelope and stable-key index. `runtime_lowered` is an
authored string field whose normalized value remains `false`; the schema adds
no handler, CLI, Agent, MCP or playable flow.

The owning generator reproduces all three schema segments and the project file
byte-for-byte. Checksum-bound Sora 0.3.0 accepts all 94 isolated tables.
